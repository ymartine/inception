# User Documentation

## Starting the stack
```bash
make
```

## Stopping the stack
```bash
make down
```

## Accessing the website
- Website: https://yamartin.42.fr
- Admin panel: https://yamartin.42.fr/wp-admin

## Credentials
Credentials are stored in the `srcs/.env` file. Contact the administrator for access.

## Basic checks
- Check running containers: `docker ps`
- Check logs: `docker logs <container_name>`
- Check volumes: `docker volume ls`
